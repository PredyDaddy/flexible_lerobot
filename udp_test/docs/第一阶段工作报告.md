# 第一阶段工作报告

本文档记录本阶段 `JZRobotUDP` 只读链路的开发结果，方便后续 push 到 x86 后继续联调。

## 阶段目标

本阶段目标是先把 x86 侧的 `get_observation()` 跑通，不做机器人控制。

当前完成的是：

```text
Orin / ARM:
  ROS2 state topic -> UDP state packet

x86:
  UDP state packet + RTSP camera -> JZRobotUDP.get_observation()
```

当前明确不做：

```text
不 send_action
不 publish ROS command topic
不 cmd_vel
不控制手臂
不控制夹爪
不做 UDP command packet
```

  缓存最新 UDP state

  x86 后台 UDP 接收线程
  只 bind + recvfrom
  不发送控制包

rtsp_camera.py
  x86 通过 OpenCV 读取 RTSP
  校验图像 shape
  默认 BGR -> RGB

jz_robot_udp.py
  实现 Lerobot Robot 接口
  connect()
  disconnect()
  get_observation()
  observation_features
  action_features = {}
  send_action() 直接抛 NotImplementedError

```text

后续如果要改 dataset schema，需要单独讨论，不在第一阶段改
```

## 子代理审核结论

本阶段开了子代理做只读风险审核。

审核结论摘要：

```text
核心 JZRobotUDP readonly 路径未发现控制发送风险
没有 ROS command publisher
没有 cmd_vel
没有 command topic 发布
send_action() 直接抛异常
Orin bridge 是 subscription-only
```

审核发现并已处理的问题：

```text
x86 先启动后 Orin 再启动可能超时
  已将 connect_timeout_s 调整为 300 秒

connect 可能复用旧 cache
  已改成 connect 后必须等 fresh packet

协议 gripper 校验过宽
  已强制 grippers.left/right.width/force 必须存在

UDP state 接收没有 sender 过滤
  已增加 allowed_sender_ip，默认 192.168.1.81

Orin start 默认调用 readiness 脚本影响只读证明范围
  已改成默认不跑，RUN_READINESS=1 时才跑

RTSP 图像 shape 没有校验
  已增加 shape 校验，默认 RGB 输出
```
