# train_all 运行命令

## 1. 准备环境

如果 `vlash_train` 已经存在，可以跳过本步骤。需要重建或确认依赖时运行：

```bash
cd /data/cqy_workspace/flexible_lerobot
bash my_devs/vla_engineering/train_all/scripts/env_setup.sh
```

该脚本保持与历史 `my_devs/vla_engineering/train/env_setup.sh` 一致的训练环境基线：

```text
conda env: vlash_train
python: 3.10
transformers: 4.53.3
peft: 0.18.1
bitsandbytes: 0.48.2
dataset video_backend: pyav
```

## 2. 离线资产检查

```bash
cd /data/cqy_workspace/flexible_lerobot
bash my_devs/vla_engineering/train_all/scripts/prepare_offline_assets.sh
```

检查内容：

```text
assets/modelscope/google/paligemma-3b-pt-224
assets/modelscope/lerobot/pi05_base
datasets/desk_cleanup_v1/eraser_cup_multi_task
```

## 3. 数据集探针

```bash
cd /data/cqy_workspace/flexible_lerobot
source /home/cqy/miniconda3/etc/profile.d/conda.sh
conda activate vlash_train

export PYTHONPATH=/data/cqy_workspace/flexible_lerobot/my_devs/vla_engineering/vlash-main:/data/cqy_workspace/flexible_lerobot/src:${PYTHONPATH}
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
export TOKENIZERS_PARALLELISM=false

python my_devs/vla_engineering/train_all/scripts/probe_dataset.py \
  --max-delay-steps 1 \
  --sample-index 0
```

## 4. Smoke Train

这是正式训练前必须先通过的最小训练链路。

```bash
cd /data/cqy_workspace/flexible_lerobot
bash my_devs/vla_engineering/train_all/scripts/run_smoke_train.sh
```

成功后应看到：

```text
train_all VLASH PI0.5 delay LoRA smoke run complete.
POLICY_PATH=.../train_all/outputs/pi05_so101_delay_lora_smoke/checkpoints/last/pretrained_model
```

## 6. Checkpoint Action Smoke

```bash
cd /data/cqy_workspace/flexible_lerobot
source /home/cqy/miniconda3/etc/profile.d/conda.sh
conda activate vlash_train

export PYTHONPATH=/data/cqy_workspace/flexible_lerobot/my_devs/vla_engineering/vlash-main:/data/cqy_workspace/flexible_lerobot/src:${PYTHONPATH}
export HF_HUB_OFFLINE=1

python my_devs/vla_engineering/train_all/scripts/smoke_checkpoint.py \
  --policy-path my_devs/vla_engineering/train_all/outputs/pi05_so101_delay_lora_smoke/checkpoints/last/pretrained_model \
  --device cuda \
  --num-inference-steps 2
```

## 7. 正式训练

Smoke train 通过后，手动启动正式训练：

```bash
cd /data/cqy_workspace/flexible_lerobot
FORCE_RESTART=true \
bash my_devs/vla_engineering/train_all/scripts/train_delay_lora.sh
```

默认正式配置：

```text
config: my_devs/vla_engineering/train_all/configs/train/pi05_so101_delay_lora_r192.yaml
output: my_devs/vla_engineering/train_all/outputs/pi05_so101_delay_lora_r192
lora.r: 192
lora.alpha: 192
steps: 66550
max_delay_steps: 1
shared_observation: false
```

## 8. Delay 覆盖实验

不改 YAML，只用 CLI override 覆盖 delay：

```bash
cd /data/cqy_workspace/flexible_lerobot
FORCE_RESTART=true \
OUTPUT_DIR=/data/cqy_workspace/flexible_lerobot/my_devs/vla_engineering/train_all/outputs/pi05_so101_delay_lora_r192_delay8 \
bash my_devs/vla_engineering/train_all/scripts/train_delay_lora.sh \
  --output_dir=/data/cqy_workspace/flexible_lerobot/my_devs/vla_engineering/train_all/outputs/pi05_so101_delay_lora_r192_delay8 \
  --job_name=pi05_so101_delay_lora_r192_delay8 \
  --max_delay_steps=8
```

建议第一批按顺序比较：

```text
max_delay_steps=0
max_delay_steps=1
max_delay_steps=4
max_delay_steps=8
max_delay_steps=12
max_delay_steps=15
```
