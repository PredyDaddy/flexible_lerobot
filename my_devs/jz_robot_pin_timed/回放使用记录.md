# jz_robot_pin_timed 回放流程

## 1. 回放前检查

确认数据路径中存在：

```text
meta/info.json
meta/episodes/
data/
videos/
```

timing sidecar 不参与动作回放，只用于分析采集时序。回放脚本关闭 RTSP 相机，因此不会额外占用
三路视频解码资源。

先确认机器人当前姿态与 episode 第一帧 action 足够接近。`MAX_INITIAL_JOINT_DELTA_RAD` 和
`MAX_JOINT_STEP_RAD` 默认都是 0.02 rad；不要为了通过检查直接放大，除非现场已经单独评估。

## 2. Orin 启动 state + executor

```bash
cd /home/data/test/workspace/flexible_lerobot

JZ_UDP_EXECUTOR_ARMED=1 \
bash my_devs/jz_robot_pin_timed/edge/start_pin_replay.sh
```

等待 `replay services ready`。

## 3. x86 先 dry-run

`dry_run` 仍读取真实 state 并按 episode 走完整循环，但 executor 不应发布 armed ROS command。

```bash
cd /home/luzhuang/cqy/aaa/flexible_lerobot
conda activate lerobot_flex

DATASET_NAME=jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
DATASET_ROOT=/home/luzhuang/cqy/aaa/flexible_lerobot/tests/outputs/jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
DATASET_REPO_ID=local/jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
EPISODE=0 \
EXECUTION=dry_run \
REPLAY_FPS=30 \
bash my_devs/jz_robot_pin_timed/x86/start_pin_replay.sh
```

确认数据路径、episode 帧数、state 接收和安全检查都正常。

## 4. armed 回放单条 episode

现场急停和软件阈值确认完成后：

```bash
cd /home/luzhuang/cqy/aaa/flexible_lerobot

DATASET_NAME=jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
DATASET_ROOT=/home/luzhuang/cqy/aaa/flexible_lerobot/tests/outputs/jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
DATASET_REPO_ID=local/jz_robot_pin_timed_real_YYYYMMDD_HHMMSS \
EPISODE=0 \
EXECUTION=armed \
REPLAY_FPS=30 \
JZ_ROBOT_PIN_ARMED=1 \
I_UNDERSTAND_JZ_ROBOT_PIN_MOVES_ROBOT=1 \
bash my_devs/jz_robot_pin_timed/x86/start_pin_replay.sh
```

三条数据逐条执行，依次把 `EPISODE` 改为 `0`、`1`、`2`。不要并发启动多个 replay。

## 5. 停止

x86 回放前台使用 `Ctrl+C`。随后在 Orin：

```bash
cd /home/data/test/workspace/flexible_lerobot
bash my_devs/jz_robot_pin_timed/edge/stop_pin_replay.sh
```

## 6. 常见失败

- `Timed out waiting for ... state packet`：Orin state bridge 未就绪、目标 x86 IP 错误，或 x86
  另一个 recorder/control/probe 已经占用 `39010`。
- `initial joint delta exceeds limit`：机器人当前姿态和 episode 第一帧动作不一致；先重新对齐，
  不要默认关闭检查。
- `step joint delta exceeds limit`：数据相邻 action 超过当前阈值；先离线检查具体 joint 和幅度。
- 找不到数据：同时核对 `DATASET_ROOT` 与 `DATASET_REPO_ID`，不要只修改 `DATASET_NAME`。
- Robot 类型日志不是 `jz_robot_pin_timed`：应从本目录的 `replay.sh` 或 x86 wrapper 启动。
